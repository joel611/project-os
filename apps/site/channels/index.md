# Inbound channels

An inbound channel is where information reaches project-os. Your team keeps working where it already does.

| Channel               | Ask questions | Gets answers | Adds to Project Memory |
| --------------------- | ------------- | ------------ | ---------------------- |
| [Discord](discord.md) | Yes           | Yes          | Yes                    |
| [Email](email.md)     | No            | No           | Yes                    |

What project-os keeps from a channel belongs to one project.
